# SimpleFOC実機試験：判明事項・課題・対応予定

更新日：2026-11-17。対象：V2806-KV400／B-G431B-ESC1／AS5047P ABI。

## 結論と中断時の状態

**短時間の閉ループ回転は継続できるようになったが、滑らかな定速回転は未達成。原因はまだ特定できていない。**

ユーザーの「切りの良いところでやめて」という指示を受け、追加試験は行わず記録をまとめた。明示的な再開指示までは、駆動・書込み・リセットを行わない。

| 項目 | 現在の状態 |
| --- | --- |
| 実機ファームウェア | DIAG v84。起動だけでは回転しない |
| 出力 | OFF。停止応答、全駆動ロック、running=0／Uq=0の5行を確認 |
| 再駆動 | 現在の起動では禁止。ロック解除には明示的なリセットが必要 |
| ホスト側処理 | 記録・書込み・駆動プロセスは終了済み |
| 最終確認ログ | [v84停止・駆動ロック](experiment-logs/2026-11-17-profile-v84-idle-01.log) |
| 電源の試験条件 | ユーザー指定11.1V・電流制限0.8A。これ以上の増加は許可されていない |
| 物理条件 | ユーザー報告ではモーター固定、負荷・プロペラなし。現在の電源スイッチ状態はソフトから確認していない |
| 磁石の中心ずれ | ユーザーが再確認し「磁石はずれていない」と報告。位置を変更したとの報告はない |

CV維持の追加質問はしないというユーザー方針に従い、後半は取得できるVBUS・速度・ADC・停止応答を監視した。CVフラグや実際のモーター温度を測定したわけではない。

## 判明したこと

### 1. 分解能と速度推定の問題は切り分け、修正した

- Index間は、2回の手回しで計4区間とも4000カウント。1000PPR・4逓倍へ校正した。
- 旧速度推定は、不定速の同じ手回しに対して移動量の積分が約44～46%過大だった。
- 修正後の同じ手回しでは、角度差19.289379radに対し、新速度の積分19.290393rad、新LPFの積分19.290398rad。差は約0.0053%。
- 手回しが不定速であること自体を異常とは判定していない。同じ運動について角度差と速度積分を比較した。

この修正は移動量の整合を改善したが、センサーの絶対角度精度やすべての瞬間速度を保証するものではない。

根拠：[手回し記録](experiment-logs/2026-11-16-manual-diag-02.log)、[推定器と保存エッジの検証コード](../test/velocity_replay.cpp)。

### 2. 実際に回転でき、閉ループの長い停滞は大きく減った

旧電圧制御では、静止に近い状態から急に動く区間や、速度保護による途中停止があった。出力制限の見直し、電流内側ループ、速度推定・ゲインの比較により、現在は正逆とも平均約1rad/sで3秒完走する条件が得られている。

比較は原則として**開始0.8秒以降の同じ10ms角度差分**で行う。低速は絶対値0.2rad/s未満、指令と逆方向は指令方向へ符号を揃えた速度が-0.2rad/s未満。RMSは目標速度に対する追従誤差であり、速度LPF後の値だけで改善と判定しない。

| 条件 | 速度誤差RMS rad/s | 判定 |
| --- | --- | --- |
| 旧標準t・25kHzの再試験 | 1.475、低速56.5% | 強いむらが残る比較基準 |
| 電流制御・回帰速度4ms、速度I=4.80 | 正方向.361～.403、逆方向.341～.384 | 回転継続は改善したがむらは残る |
| 速度I=7.20・正方向3回 | .339／.362／.360 | 同一ファームのI4.80基準.380より改善傾向 |
| 速度I=7.20・逆方向3回 | .330／.314／.338 | 同一ファームのI4.80基準.361より改善傾向 |
| 速度I=9.60・正方向3回 | .325／.355／.338 | I7.20に対する追加改善は小さい |
| 速度I=9.60・逆方向3回 | 平均.32647 | 同一ファームI7.20の.33359との差は小さい |

初期角、向き合わせ、実行タイミングが異なるため、離れた世代の数値を厳密な一因子比較とは扱わない。I7.20は暫定候補であり、完成設定ではない。

根拠：[I7.20の比較波形](experiment-logs/2026-11-17-velocity-integral-comparison.png)、[逆方向比較](experiment-logs/2026-11-17-velocity-integral-reverse-comparison.png)、[全128試験の集計](experiment-logs/2026-11-17-current-control-comparison.csv)。

### 3. 周期補正は一部改善するが、効果はまだ確実ではない

機械角84次の成分を小さな電流指令で補う試作を比較した。毎回係数をゼロから学習し、補正は公称0.03A以内、合計Iq指令は±0.45A以内。開始0.8秒までは補正ゼロ、0.2秒で導入する。

最新の同一v84比較：

| 条件 | 回数 | 共通10ms RMS rad/s | その他 |
| --- | ---: | --- | --- |
| F：学習基底位相0度 | 3 | .30073／.33408／.35203 | 平均速度.99860／1.00671／1.00182。低速・指令と逆方向は全て0% |
| Z：同じ計算経路で補正ゼロ | 2 | .35757／.35459 | 低速は各約.46%、指令と逆方向0% |
| A：従来の学習基底位相45度 | 1 | .36054 | 低速約.91%、指令と逆方向0% |

Fの試験ごとのRMS平均は.32895、Zは.35608で約7.6%の差。ただし初回ほどの改善が再現せず、84次成分そのものも今回一貫して減っていない。**A/Fは採用済みの解決策ではない。** 学習基底位相の変更はFOC電気角合わせの変更ではない。

根拠：[6試験の集計・監査](experiment-logs/2026-11-17-adaptive84-zero-lag-comparison.json)、[比較波形](experiment-logs/2026-11-17-adaptive84-zero-lag-comparison.png)。

### 4. 応答位相・磁石・センサーについて断定できる範囲

- 公称0.02Aの既知の正弦波を加えた測定では、17.5Hz・4回の速度応答位相は-7.41～+5.64度、複素平均約-1.90度だった。少数の指令クリップがある回もあり、局所的な閉ループ応答の観測である。
- 13.5Hzは測定区間を分けた位相差が最大147度に達し、位相を確定できなかった。17.5Hzの結果をそのまま13.5Hzへ適用しない。
- 駆動中のABI不正遷移・重複は最新試験で0。独立カウントとEncoderカウントは一致した。ただし、磁気的な角度誤差はこの検査だけでは除外できない。
- Index参照の向き合わせ結果を48試験・7位置群へ拡大した。1次＋2次の位置依存モデルの位置群除外交差検証RMSは.01183rad、定数モデルは.01343rad。差は小さく、センサーの歪み・モーターの磁極位置・摩擦を分離できない。
- ユーザーは磁石の中心ずれを再確認して否定した。中心ずれを主因として扱ったり、位置変更済みと記録したりしない。

根拠：[応答測定](experiment-logs/2026-11-17-velocity-response-comparison.json)、[48試験の向き合わせ比較](experiment-logs/2026-11-17-alignment-repeatability-expanded.json)。

## 残っている課題と対応予定

再開後も、電圧・電流・速度の上限や保護を緩めて成功とは扱わない。比較は一度に一つの条件を変え、同一ファームウェアの基準試験を挟んで行う。

| 優先度 | 課題 | 対応予定・判定方法 |
| --- | --- | --- |
| 1 | 目標1rad/s付近にも約.3～.4rad/s RMSのむらが残る | 周期補正を切ったI7.20/P.15を基準にする。速度Pだけ.20へ変える案を、既存の電流ループ・量子化速度・保護を含むモデルで先に検証。その後に短時間の基準／候補比較を行う。**このP変更は未実装・未試験** |
| 2 | むらが機械角依存か、制御応答・電流観測に由来するか未分離 | 速度・Iq指令／観測値・d/q電圧・ABI角度を同時に比較。角度に同期する成分と時間周波数成分の再現性を正逆で確認する。単一の周波数一致だけでコギングと断定しない |
| 3 | 13.5Hzの位相が不安定で、周期補正の前提が弱い | 必要なら既存上限20Hz／公称.02A以内で正逆位相の反復測定。分割区間と反復間で整合しない結果は補正係数に使わない |
| 4 | 磁気的な角度精度は独立に検証していない | 中心ずれの否定と角度精度の検証を区別する。必要性が明らかになれば、独立角度基準やAS5047Pの磁界診断を検討。現在はABI接続で、SPI診断値は読んでいない。追加配線を無断で前提にしない |
| 5 | 相電流・温度・電源状態の保護に限界がある | 相電流換算の校正、測定同期・ゲイン・符号、温度換算と保護の妥当性を別途検証する。0.8A電源制限や±.45A指令を、実相電流の上限保証と説明しない |
| 6 | 安定回転の判定を平均速度だけで行えない | 共通10msのRMS・低速／逆方向割合・ピーク・電流追従・正逆の再現性を併用。高密度の末尾約.65秒だけの記録を、運転全体の成功の根拠にしない。最終的な許容値は未確定 |

## 再開時に維持する条件と注意点

- 電源11.1V・電流制限0.8A以内、負荷・プロペラなし、モーター固定。接続・作業終了・変更点を確認してから駆動する。
- 現在の実機PWMは12.5kHz、公称dead time 800ns。**ソースのPWM既定は25kHz**であり、再現ビルドには`DIAG_PWM_HZ=12500`が必要。
- 暫定候補I/R：目標±1rad/s、速度P=.15/I=7.20、回帰速度履歴4ms、速度LPF2ms、電流qPI=.60/200、電流LPF2ms。
- 運転中の合成電圧上限.5V、Iq指令±.45公称A、独立した速度保護5rad/s、3秒上限、動き停止・非有限値・ADC鮮度／範囲・VBUS逸脱等の保護を維持する。
- 向き合わせは.7V・3電気回転の往復、約14秒＋初期化。向き合わせ中は電圧駆動で、校正済み相電流制限はない。停止文字を監視するが、motor.init()の約1秒は即応しない。
- 1起動1試験。ホストは自動リセット・自動再試行をしない。PWM・実ゲイン・実LPF等が要求と違えば停止する。
- 明示的なリセットには`tools/reset_board.py --output .pio/未使用ログ名.log`を使う。OpenOCDはエラーでも終了0になる事例があったため、完了印とエラー行も検査する。
- ログを先に取得してから操作を案内する。回転のむらはエージェントがログで判断し、目視での滑らかさやCVを繰り返し質問しない。

## ソフトウェアと検証

依存はststm32@20.0.0、Arduino core 2.12.0、SimpleFOC 2.4.0で固定。`lib_archive=no`、`HAL_OPAMP_MODULE_ENABLED`が必要。依存ライブラリのソースは変更していない。

Windowsで実機と同じ条件の**ビルドだけ**を行う例：

```powershell
$env:PLATFORMIO_BUILD_DIR="$PWD/.pio/observer-build"
$env:PLATFORMIO_BUILD_FLAGS='-DDIAG_PWM_HZ=12500 -DHAL_OPAMP_MODULE_ENABLED'
& "$env:USERPROFILE/.platformio/penv/Scripts/pio.exe" run -j 4
```

v84のビルドは成功。RAM 30,156／32,768B（92.0%）、Flash 94,012／131,072B（71.7%）。RAMの余裕は小さく、追加計測では容量・制御周期への影響を確認する。

中断時にC++の14検証をMSVCで再コンパイルして実行し、Pythonの4検証も全て成功した。保存ログ再生、推定器、出力制限、電流PI、保護、ABI診断、周期補正モデル、解析時刻・応答位相・リセット成否判定を含む。モデルは実機同定や実際の温度・相電流保護の証明ではない。[再検証ログ](experiment-logs/2026-11-17-checkpoint-native-validation.log)に結果を保存した。

詳細な操作上の引き継ぎは[AGENTS.md](../AGENTS.md)、実装は[src/main.cpp](../src/main.cpp)、証跡は[実験ログ](experiment-logs/)を参照。
