## テスト動作

- 現在の許可条件は電源11.1V・電流制限0.8A。プロペラと負荷を外してモーターを固定。
- 起動時はPWMドライバーを無効化。自動回転しません。
- シリアルの`t`で閉ループ試験を1回だけ実行。0.7Vでセンサー方向・電気角を合わせます。
  この間は3電気回転（機械角約154度）ずつゆっくり往復し、各端点で700ms待機します。
  往路・復路それぞれの1電気回転あたりの誤差が0.5rad以内か確認し、失敗時は停止。
- 成功時は速度1rad/s（約9.55rpm）、駆動電圧上限0.5Vで3秒間回転し、出力を無効化。
- 速度が5rad/sを超える・数値異常・1.2秒後も変位0.03rad未満なら停止。
- `s`で回転停止。向き合わせ中も`s`を監視します。ライブラリの初期化中（約1秒）の
  `s`は処理完了後に反映されます。即時停止は主電源遮断。
- 1起動につき1回のみ。再試験にはリセットが必要です。
- `r/n/m`のみ公称相電流のフィードバックを使用。電圧制限や推定Iq指令の上限は正確な相電流上限を保証しません。
  CC動作、電圧低下、発熱、異音があれば主電源を切り、電流制限を上げないでください。
- 出力CSV: ms,running,A_edges,B_edges,index,angle_rad,velocity_rad_s,Uq_V

ABIは増分位置なので、起動ごとに電気角合わせを行います。
Indexは観測のみで原点補正やIndex探索には使いません。
配線変更は主電源とUSBを外して行ってください。
