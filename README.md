# SimpleFOC / B-G431B-ESC1 low-speed test

V2806-KV400: 12N14P、極対数7。AS5047P ABI: 1024 PPR / 4096 counts/turn仮設定。
手動回転試験で約1回転にA/Bそれぞれ約2048エッジ、Index 1回を確認済みです。
厳密な分解能校正はまだ行っていません。

| ESC J8 | AS5047P adapter |
| --- | --- |
| 5V | 5V (P1-1), 5V動作設定 |
| GND | GND (P1-8) |
| A+/H1 (PB6) | A (P1-10) |
| B+/H2 (PB7) | B (P1-9) |
| Z+/H3 (PB8) | I/PWM (P1-11), Index出力設定 |

## ビルド・書き込み

```sh
pio run
pio run -t upload
pio device monitor -b 115200
```

STM32 Arduino core 2.12.0とSimpleFOC 2.4.0を固定しています。
lib_archive=noでSTM32用PWM実装をリンクします。
core 3.0.0ではSimpleFOCのenableTimerClock呼び出しに互換性エラーが出ます。

## テスト動作

- 電源11.1V・電流制限0.3A、プロペラと負荷を外してモーターを固定。
- 起動時はPWMドライバーを無効化。自動回転しません。
- シリアルの`t`で閉ループ試験を1回だけ実行。0.7Vでセンサー方向・電気角を合わせます。
  この間は3電気回転（機械角約154度）ずつゆっくり往復し、各端点で700ms待機します。
  往路・復路それぞれの1電気回転あたりの誤差が0.5rad以内か確認し、失敗時は停止。
- 成功時は速度1rad/s（約9.55rpm）、駆動電圧上限0.5Vで3秒間回転し、出力を無効化。
- 速度が5rad/sを超える・数値異常・1.2秒後も変位0.03rad未満なら停止。
- `s`で回転停止。向き合わせ中も`s`を監視します。ライブラリの初期化中（約1秒）の
  `s`は処理完了後に反映されます。即時停止は主電源遮断。
- 1起動につき1回のみ。再試験にはリセットが必要です。
- 相電流検出は未実装。電圧制限は相電流の制限ではありません。
  CC動作、電圧低下、発熱、異音があれば主電源を切り、電流制限を上げないでください。
- 出力CSV: ms,running,A_edges,B_edges,index,angle_rad,velocity_rad_s,Uq_V

ABIは増分位置なので、起動ごとに電気角合わせを行います。
Indexは観測のみで原点補正やIndex探索には使いません。
配線変更は主電源とUSBを外して行ってください。

## 実機試験結果

2026-11-15: PWM初期化・書き込み検証成功。向き合わせ0.3V/0.5V/0.7Vで
軸の動きを検出したものの、極対数推定10.81/8.27/7.82となり、
7極対の整合チェックで停止。連続速度制御試験は未実施。
0.3V試験時はユーザーよりCV維持・異常なしの報告。
0.7V試験時はユーザーよりCV維持・約0.2Aとの報告。
チェックは無効化していません。停止後は出力無効、再起動後も待機状態です。

追加試験: 通常の向き合わせ0.9Vでも推定7.71でチェック失敗。
0.7V・4ms/step・3電気回転・端点700ms待機に変更し、
往路2.61084rad/復路2.60777radを測定。1電気回転あたりの誤差は
約0.19/0.20radで0.5rad許容範囲内。方向・電気角合わせ成功。
速度指令1rad/sで駆動し、開始角-0.00767radから約0.43718radまで動いたが、
約1秒後に速度保護（5rad/s超）で出力無効化。
3秒の安定回転は未達成。次は速度検出・コギング・制御ゲインの調整が必要。
最終状態は出力OFF、自動再試行なし。

ゲイン調整後（P=0.08, I=0.15, LPF=0.05s, 出力ランプ0.3V/s）も再試験。
向き合わせ往路2.60317rad/復路2.59396radで合格。
速度制御中は0.43258radから1.12287rad（約39.6度）まで断続的に回転し、
約2.2秒後に同じ速度保護で停止。安定回転は未達成。
最終ファームウェアはこのゲイン設定。出力OFFで待機。

## オープンループ切り分けモード

`o`で、同じ向き合わせを実施後、その終端の電気角から0.7V一定で
速度を0から3rad/sへ800msかけて上げ、3秒で出力OFFにします。
速度PIDは使いません。ABIは独立した速度観測・5rad/sの停止保護に使用します。
初回の無整列開始では軸が引き寄せられ保護停止したため、終端電気角を合わせるよう修正済み。
修正後の実測では角度-0.30066radから1.23332rad（約87.9度）まで回転したが、
約1秒後に速度保護で停止。3秒間の連続回転は未達成です。
速度PIDを除いても停止するので、電流・駆動波形・速度推定を切り分ける必要があります。
速度推定のスパイクと実際の速度変動のどちらかはまだ確定していません。
この試験後も出力OFF、自動再試行なし。
